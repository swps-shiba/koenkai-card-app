# 後援会カード管理アプリ

「いんどう周作 後援会 入会お申込書」カードをスマホで撮影して管理・活用するPWA（Webアプリ）です。

- カード一覧・検索、詳細はタップで表裏フリップ、「前へ/次へ」ボタンで前後のカードへ移動
- 住所タップでGoogleマップのナビ、電話番号タップで発信
- 郵便番号から住所を自動入力（町域まで）
- 訪問・電話の記録を追加/編集（確認は✓表示、タップで確認者と日時を表示）
- データは端末内に保存（ローカルファースト）。パスコードでロック

設計の詳細は [DESIGN.md](DESIGN.md) を参照してください。
